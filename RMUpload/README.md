# RMUpload

iOS app (built with [xtool](https://github.com/xtool-org/xtool)) that uploads PDF and EPUB files
to your reMarkable cloud account, using the same API as the "Read on reMarkable" Chrome extension.

## Build & install

```sh
xtool dev          # build, sign and install on a connected device
xtool dev build    # build only -> xtool/RMUpload.app
```

## Usage

- Log in with your reMarkable account (Auth0 login sheet).
- Tap **+ → Files…** to pick PDFs/EPUBs, or from any app use **Share → RMUpload** (Open in…).
- Tap **+ → Webpage…** and enter a URL, or in Safari use **Share → RMUpload**: the page is
  rendered off-screen into a paginated PDF (3:4 pages, the reMarkable's shape) and queued.
- Optionally convert EPUBs into notebooks, then tap **Send to reMarkable**.
  Files land in the root folder of your reMarkable.

## How it works

- Auth: Auth0 authorization code + PKCE against `auth.remarkable.com` with the extension's client ID
  and its registered `chrome-extension://…/callback.html` redirect, which `ASWebAuthenticationSession`
  intercepts. Tokens (incl. rotating refresh token) are stored in the Keychain.
- Upload: `POST https://web.{tectonic}.tectonic.remarkable.com/import/v1/files` with the raw file body,
  `Authorization: Bearer …`, `rM-Source: RoR-Browser` and `rM-Meta: base64(JSON{file_name, parent, …})`.
  The tectonic region comes from the `https://auth.remarkable.com/tectonic` ID-token claim.

- Webpages: the `RMUploadShare` share extension forwards the link to the app as
  `rmupload://add?url=…`; the app renders it with WKWebView + UIPrintPageRenderer.

- Reader mode (on by default) runs `reader.js` (the extension's Readability + DOMPurify, generated by
  `../tools/build_reader.py`) in the loaded page and prints just the article text and images.
  Pages without a readable article are printed in full.

This uses reMarkable's private API and the extension's OAuth client; it may break whenever they change it.
